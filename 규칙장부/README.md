# 규칙장부 — 무엇을 어디에 적는가

검수 규칙 한 건이 제안에서 적용까지 가는 길을 **기록으로** 남기는 자리다.
포털 운영 데이터(지적·이력·후보)는 지금처럼 자료함(DB)에 있다. 같은 것을 두 곳에 적지 않는다.

| 장부 | 파일 | 무엇을 적나 | 누가 적나 |
|---|---|---|---|
| 자료 목록 | `자료목록.md` | 무엇이 정본인지 · 사본을 치우는 조건 | 사람(확정) — 숫자는 프로그램 |
| 규칙 장부 | (③단계) | 사건 하나 = 한 줄(등록→승인→검증→반영) | 사람·프로그램 |
| 측정 장부 | (②단계) | 한 번 재기 = 한 줄(지문·설정·정답·원본 결과) | 프로그램만 |

`자료/` 는 프로그램이 잰 원본 결과를 두는 자리다. 사람이 고치지 않는다.

도구:

```
python3 규칙장부/도구/자료점검.py --자료뿌리 ~/dev-screen-qa
```

읽고 나서 판단이 필요한 것은 `자료목록.md` 4절 "아직 못 믿는 것"에 남긴다.
잰 것이 빠졌거나 실행이 막히면 '통과'가 아니라 **판정 불가**로 적는다.
