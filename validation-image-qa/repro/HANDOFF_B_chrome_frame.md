# B 조각 — 게시판의 「가짜 브라우저 틀」을 틀 판정이 못 잡는 구멍

**여기서 일한다:** `/Users/designgroup_02/dev-screen-qa` · 브랜치 `feat/image-qa-chrome-frame`
(검수 자료 PNG·elements JSON이 이 폴더에만 있으므로 **재기(측정)는 여기서만 된다.**)

## 무엇이 문제인가
디자인 시안에 그려 넣은 **가짜 브라우저 창 틀**(주소창·탭 줄)은 검수 대상이 아니다.
위쪽 띠 판정(`bands`)이 이것을 잡아 제외해야 하는데, 게시판 화면에서는 **이름도 글자도 없어서** 못 잡는다.
지금은 다른 규칙(#13 캡처 밖 자리 제외)이 **우연히** 걸러 줄 뿐이라 근본이 남아 있다. (근거: `RULE_PROPOSALS.md` #13 “남은 메모”)

## 할 일
1. 게시판(board)에서 가짜 틀에 해당하는 요소가 무엇으로 들어오는지 본다(`b0_board.json`의 `units`).
2. 띠 판정(`ui.html`의 `bands`)이 **글자 없는 틀**도 잡도록 보강한다.
3. 화면 10개로 재서 **볼 것·정답·자체 검사 174개**를 확인하고, `RULE_PROPOSALS.md`에 규칙 기록을 남긴다.
4. 커밋 전 멈추고 river님께 보고(그림·표로).

## 재는 법
`RULE_PROPOSALS.md` 아래쪽 계측 기록과 `HANDOFF_next.md` 4절 표 참조. 기준선은 **볼 것 331 · 밀림 8**(커밋 940a994).
