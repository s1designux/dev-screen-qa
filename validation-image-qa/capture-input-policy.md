# 시안 기준 촬영 입력 규정

2026-09-09 사용자 승인. 시안에 적힌 내용을 기준으로 TC를 만들고 실제 앱을 촬영할 때 적용한다.

1. 보이는 입력값은 시안과 문자 단위로 같아야 한다. 대소문자, 공백, 기호, 줄바꿈도 포함한다. 임의 테스트 문자열로 바꾸지 않는다.
2. 입력값과 안내 문구(placeholder)를 구분한다. 시안이 빈 입력칸이면 실제로 비운다. 안내 문구를 입력값으로 타이핑하지 않는다.
3. 가려진 비밀번호는 가림 상태와 화면에 보이는 점 개수를 일치시킨다. 점으로 원래 비밀번호를 추측하지 않는다. 점 개수가 확인된 경우에만 같은 개수의 비밀이 아닌 테스트 문자열로 재현한다. 실제 앱의 표시 개수도 캡처로 확인한다.
4. 비밀번호 표시 상태는 시안에 보이는 문자열 자체가 기준이다. 다른 시안의 숨김 비밀번호와 같다고 추정하지 않는다.
5. 근거는 사용자 명시값 또는 읽을 수 있는 원본 시안이다. 출처와 미확인 항목을 TC에 기록한다. 축소 이미지에서 읽히지 않는 값은 null/확인 대기로 남기며 임의 보충하지 않는다.
6. 언어·버튼 상태·포커스·키보드·스크롤·촬영 영역과 입력 내용 일치를 따로 확인한다. 상태만 맞았다는 이유로 입력값까지 일치했다고 표시하지 않는다.
7. 기준값 미확정 TC는 정확 일치 재촬영을 보류한다. 이미 찍힌 임의값 캡처는 이전 탐색 이력으로 보존하고 현재 일치 결과로 표시하지 않는다.
8. 로그인 제출은 상태 촬영에 필요하지 않으면 수행하지 않는다. 실제 비밀정보를 수집하거나 저장하지 않는다. 완료 후 입력한 내용을 제거한다.
9. 캡처 이미지는 실제 화면 그대로 보존한다. 글자나 점을 이미지 편집으로 교체하지 않는다. 결과는 사람이 최종 판단하며 자동으로 오류 확정하지 않는다.

이 규정은 촬영용 TC 규정이다. 검수 정책의 표 본문 가변 영역 등 별도 비교 규칙을 덮어쓰지 않는다.
