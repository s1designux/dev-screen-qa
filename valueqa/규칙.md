# 개발 관행 표 — 개발이라서 그런 것은 지적하지 않는다

값 대조(`valueqa/`)가 **구조 차이**(개발에만 있음 / 시안에만 있음)를 올리기 전에 거치는 표다.
표는 `valueqa/개발관행.py` 한 곳에 있고, 이 문서는 그 사본이다 — **코드가 원본이다.**

새 줄을 더할 때 지키는 것 셋:

1. **근거 화면을 적는다.** 어느 화면에서 몇 건이 왜 잘못 올라왔는지 없이 줄을 더하지 않는다.
2. **접은 것은 지우지 않는다.** 후보에서 빼되 회차(`auto_run.notices`)에 규칙별 건수로 남는다.
3. **자동으로 확정하지 않는다.** 표는 볼 것을 줄일 뿐, 통과·지적을 정하지 않는다(CLAUDE.md 2번-2).

| id | 갈래 | 무엇을 접나 | 왜 |
|---|---|---|---|
| `dev.안보이는상자` | 더있음 | 칠도 테두리도 없는 상자 | 화면에 아무것도 안 그려지는 것이라 개발이 만들 일도 고칠 일도 없다. |
| `dev.겹친두겹` | 더있음 | 같은 자리에 겹쳐 둔 두 겹(개발) | 웹은 눈에 안 보이는 입력칸(<input>) 위에 그려지는 상자(<span>)를 얹어야 체크상자·라디오를 마음대로 그릴 수 있다. 둘 중 하나는 짝이 지어지고 남은 하나가 '디자인에 없는 요소'로 올라와 같은 것이 번호만 달리해 두 번 지적됐다. (근거: 우비스 버스 서비스 이용 약관 동의 · 체크상자 4개) |
| `dev.짝안에듦` | 더있음 | 이미 짝지은 상자 안에 든 것(개발) | 그 자리는 바깥 상자로 이미 견주었다. 안엣것까지 따로 올리면 한 곳이 여러 번 지적된다. |
| `dev.묶음상자` | 더있음 | 여러 요소를 담기만 하는 묶음 상자 | HTML 은 줄·칸을 묶는 상자(div·ul·li·header·footer)가 반드시 있어야 배치가 된다. 시안에는 그 묶음이 값 없는 프레임으로만 있어 이미 빠지므로, 개발 쪽만 남아 통째로 '디자인에 없는 요소'가 된다. (근거: 우비스 버스 홈 — #header·#footer·공지 묶음 등) |
| `dev.시안밖` | 더있음 | 시안이 그려지지 않은 아래쪽 | 디자이너가 화면 한 판만 그려 두면 개발 화면은 그보다 아래로 더 이어진다. 거기 있는 것은 '디자인에 없는 요소'가 아니라 **견줄 시안이 없는 것**이다. (근거: 우비스 버스 홈 — 시안 1080~1495 · 개발 1730, 바닥글이 통째로 올라왔다) |
| `dev.건너뛰기링크` | 더있음 | 접근성 '본문 바로가기' 링크 | 웹 접근성 지침이 요구하는 것이라 시안에 없어도 있는 게 맞다. 평소에는 화면에 안 보이고 키보드 초점이 갔을 때만 나타난다. (근거: 우비스 버스 모든 화면 · a.to-content) |
| `design.안그려진껍데기` | 빠짐 | 시안 그림에 자국이 없는 껍데기 | 간격을 띄우려고 깔아 둔 투명 프레임이다. 화면에 안 보이니 개발이 만들 것도 없다. |
| `design.짝안에듦` | 빠짐 | 이미 짝지은 상자 안에 든 것(시안) | 그 자리는 바깥 상자로 이미 견주었다. |
| `design.겹친두겹` | 빠짐 | 같은 자리에 겹쳐 둔 두 겹(시안) | 시안에서도 컴포넌트 껍데기와 속이 같은 자리에 겹쳐 있을 수 있다. |

## 표에 넣지 않은 것

- **`::before`/`::after` 로 그린 조각** — 시안에도 같은 구분선이 있어 짝이 맞으면 붙는다. 규칙으로 접으면 진짜 차이를 놓친다.
- **묶음 상자 중 하나만 품은 것** — 껍데기인지 진짜 상자인지 가를 수 없다. 사람이 본다.

## 세는 법

```bash
python3 -m valueqa 시안.json 개발값.json
```

돌리면 `접은 것 N — 규칙별 건수` 가 함께 나온다. 포털은 같은 셈을 `auto_run.notices` 에 넣어 둔다.
