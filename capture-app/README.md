# 촬영기 (capture-app)

앱 개발화면을 화면·상태별로 찍어서, 포털이 알아보는 이름으로 한 폴더에 쌓는다.

검수는 하지 않는다. **찍고 이름 붙이는 것까지**가 이 프로그램의 일이다.
포털과의 접점은 **사진 이름 규칙 하나**뿐이다 — `화면ID@상태.png` (예: `SET-AND-002@default.png`).

## 쓰는 법

브라우저에서 네 걸음으로 — 디자인 고르기 → 찍을 목록 → 조건 확인 → 전체 촬영.

```bash
./site.sh
```

열리는 주소: http://127.0.0.1:8767 (내 PC에서만 열린다)

이름표를 이미 손으로 써 두었다면 명령어로 바로 찍어도 된다.

```bash
./run.sh apps/galaxy-settings.yaml
```

사진은 `shots/날짜-시각-서비스코드/` 에 쌓이고, 같은 폴더에 `찍은목록.json`
(어느 폰·어느 해상도로 언제 찍었는지)이 함께 남는다.

## 새 앱 추가하기

`apps/` 의 이름표 한 장을 복사해서 고치면 된다. 대본(`flows/`)은 손대지 않는다.
이름표에 적는 것: 앱 이름 · 앱 주소 · 서비스코드 · 로그인 · 찍을 화면 목록(번호·이름·상태·누를 메뉴).

규칙(흐름·동작 말·이름 규칙 등)은 `규칙.md` 한 장에 모여 있다.

## 폴더

| 폴더 | 하는 일 |
|---|---|
| `apps/` | 앱 이름표 (앱마다 한 장) |
| `flows/` | 공통 대본 (앱이 늘어도 그대로) |
| `hands/` | '찍는 손' — 안드로이드는 `android.sh`, 웹 자리는 `web.sh`(아직 비어 있음) |
| `lib/` | 이름표 읽기 · 이름 붙이기 · 목록 남기기 |
| `site/` | 촬영 준비 사이트 (네 걸음 화면) |
| `plugin-pick/` | Figma 플러그인 — 드래그로 고른 화면만 보내기 |
| `shots/` | 결과 사진 (커밋 안 함) |

웹 화면도 나중에 이 틀을 그대로 쓴다. 바뀌는 것은 `hands/` 안의 손 하나뿐이다.

## 준비물

- 안드로이드 폰 + USB 케이블, 폰에서 **USB 디버깅** 켜기
- 촬영 도구 Maestro (`~/.maestro/bin`), Java 17 이상
- 안드로이드 platform-tools (`adb`)

각자 PC에 한 번에 까는 설치 묶음은 나중 조각(D)에서 만든다.
