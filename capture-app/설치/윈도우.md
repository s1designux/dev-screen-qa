# 윈도우 PC에서 쓰기 — 설치 순서

PC 웹 화면 촬영은 **폰을 꽂지 않는다.** 그래서 윈도우 PC에서 그대로 돌아간다.
(앱 촬영은 폰을 꽂아야 하므로 USB 연결 허용이 먼저다 — 아래 4번)

---

## 1. 파이썬 (한 번만)

윈도우 앱 스토어에서 **Python 3.11 이상**을 설치한다.
설치 뒤 명령 프롬프트에서 아래를 쳐 보면 번호가 나온다.

```
py -3 --version
```

## 2. 웹을 찍는 연장 (한 번만)

```
py -3 -m pip install playwright
```

**브라우저는 따로 내려받지 않는다.** 이미 깔려 있는 **크롬 → 엣지** 차례로 빌려 쓴다
(둘 다 없을 때만 딸려온 것을 쓰므로, 그때는 `py -3 -m playwright install chromium` 을 한 번 더 친다).

### 인터넷이 막힌 PC라면
다른 PC에서 아래로 파일을 미리 받아 옮긴 뒤, 그 폴더에서 설치한다.

```
py -3 -m pip download playwright -d 묶음
py -3 -m pip install --no-index --find-links 묶음 playwright
```

## 3. 찍기

이름표 한 장(`apps\*.yaml`)에 찍을 화면을 적고, 실행 파일을 부른다.

```
찍기.bat apps\웹-예시.yaml
```

사진은 `shots\날짜-서비스코드\` 에 **화면ID@상태.png** 이름으로 쌓인다.
같은 폴더의 `찍은목록.json` 이 무엇을 찍고 무엇을 못 찍었는지 적어 둔다.

촬영 준비 사이트를 열려면 `site.bat` (→ http://127.0.0.1:8767).

### 디자인 기준 TC대로 찍기 (권장)

포털에서 내려받은 `촬영요청.json` 과 주소표 한 장을 같이 준다. 시안에 있는 화면만 돈다.

```
웹TC.bat 촬영요청.json apps\웹-주소표-예시.yaml
```

**PC 웹은 값으로 검수한다.** 그림뿐 아니라 화면의 값(색·글꼴·글자크기·굵기·모서리·크기·자리)을
`*.값.json` 으로 함께 남긴다. 그림 대조는 앱·설치형 소프트웨어 쪽 이야기다.

## 4. 앱(폰) 촬영은 아직 안 된다

앱을 찍으려면 폰을 USB로 꽂아야 하는데, 사내 PC는 USB 자료 전송이 막혀 있다(2026-09-14 확인).
**담당 부서에 '개발용 단말 USB 연결 허용'을 신청한 뒤**에 아래가 추가로 필요하다.

| 필요한 것 | 비고 |
|---|---|
| 삼성 USB 드라이버 | 윈도우에서 갤럭시를 알아보게 한다 |
| Android platform-tools (adb) | 폰과 이야기하는 도구 |
| Java 17 이상 + Maestro | 촬영 도구. 윈도우용 파일을 받아 풀고 PATH에 넣는다 |

그전까지 앱 촬영은 맥에서 하고, 사진만 옮겨 쓴다.
