# 실제 화면으로 시험해 보기 (PC 웹)

폰이 필요 없다. **윈도우 PC + 브라우저**만 있으면 된다.
설치는 `설치/윈도우.md` 한 장(파이썬 + 연장 하나). 브라우저는 이미 깔린 크롬·엣지를 빌려 쓴다.

---

## 1. 주소표 한 장 채우기

`apps/웹-주소표-예시.yaml` 를 복사해 내 것으로 만든다. 채울 것은 세 칸뿐이다.

| 칸 | 무엇을 적나 |
|---|---|
| `기본주소` | 개발 사이트 주소 (예: `https://dev.내부주소`) |
| `디자인이름` | 시안 프레임 이름. 일부만 적어도 이어진다 |
| `주소` | 기본주소 뒤에 붙는 부분 (예: `/login`) |

로그인해야 보이는 화면은 `동작` 칸에 적는다. 말은 앱 촬영과 같다.

```
동작: 입력 아이디=test01 → 입력 비밀번호=1234 → 탭 로그인 → 기다림 2
```

## 2. 돌리기

**디자인 기준 TC가 있을 때** (포털에서 내려받은 `촬영요청.json`)

```
웹TC.bat 촬영요청.json apps\내주소표.yaml
```

**아직 TC가 없을 때** — 주소표만으로 돌린다(`플랫폼: web` 인 이름표)

```
찍기.bat apps\내주소표.yaml
```

## 3. 결과 보기

`shots\날짜-…\` 안에 화면마다 두 개가 생긴다.

- `*.값.json` — **검수에 쓸 값**(글꼴·글자크기·굵기·색·모서리·테두리·크기·자리)
- `*.png` — 사람이 좌우로 볼 그림

`찍은목록.json` 에 **잰 것**과 **못 한 것**이 까닭과 함께 적힌다. 못 한 것은 지우지 않는다.

---

## 잘 안 될 때

| 이럴 때 | 이렇게 |
|---|---|
| 브라우저를 못 연다고 함 | 크롬이나 엣지가 깔려 있는지 본다. 둘 다 없으면 `py -3 -m playwright install chromium` |
| "주소표에 이 디자인 이름이 없습니다" | 주소표의 `디자인이름` 을 시안 프레임 이름과 맞춘다(일부만 적어도 된다) |
| "'로그인' 을 화면에서 찾지 못했습니다" | 화면에 실제로 보이는 글자로 적는다. 늦게 뜨는 화면이면 앞에 `기다림 3` 을 넣는다 |
| 화면이 덜 그려진 채 찍힘 | 이름표 위쪽 `기다림` 숫자를 올린다 |

## 아직 안 되는 것

- 값을 **시안 값과 맞춰 차이를 뽑는 것**, 그 차이를 **포털에 후보로 올리는 것** — 다음 조각이다.
- 앱(폰) 촬영은 사내 PC의 USB 연결 허용이 먼저다(`설치/윈도우.md` 4번).
