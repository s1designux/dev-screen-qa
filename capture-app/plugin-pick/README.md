# 촬영 준비로 보내기 (Figma 플러그인)

Figma 캔버스에서 **드래그로 고른 화면만** 촬영 준비 사이트로 보낸다.
읽기만 하고 파일을 고치지 않는다. 바깥으로 나가지 않고 내 PC(127.0.0.1:8767)로만 보낸다.

## 까는 법 (한 번만)

1. 촬영 준비 사이트를 켠다 — `capture-app/site.sh`
2. Figma 데스크톱 앱 → 메뉴 **Plugins → Development → Import plugin from manifest…**
3. 이 폴더의 `manifest.json` 을 고른다.

## 쓰는 법

1. Figma에서 찍을 화면들을 **드래그로 감싸 고른다**(섹션을 고르면 그 안 화면까지 들어간다).
2. Plugins → Development → **촬영 준비로 보내기** 실행.
3. 목록을 눈으로 확인하고 **보내기**.
4. 촬영 준비 사이트로 가면 ② 찍을 목록에 그대로 들어와 있다.

폭이 1400 이상인 화면은 목록에 ⚠︎ 로 표시된다 — 폰으로 찍을 화면치고 넓다는 뜻(웹 시안을 잘못 고른 경우).
