# 검수 화면 보내기 (Figma 플러그인)

Figma 캔버스에서 **드래그로 고른 화면만** 촬영 준비 사이트로 보낸다.
읽기만 하고 파일을 고치지 않는다. 바깥으로 나가지 않고 내 PC(127.0.0.1:8767)로만 보낸다.

## 까는 법 (한 번만)

1. 촬영 준비 사이트를 켠다 — `capture-app/site.sh`
2. Figma **데스크톱 앱** → 메뉴 **Plugins → Development → Import plugin from manifest…**
3. 이 폴더의 `manifest.json` 을 고른다 — `capture-app/plugin-pick/manifest.json` 하나뿐이다.
   (2026-09-14 전에는 저장소 맨 위에도 같은 이름의 것이 있었다. 치웠다.)

폴더를 옮기거나 이름을 바꾸면 피그마가 `Locate missing manifest` 라고 한다 —
그 줄을 지우고(오른쪽 클릭 → Remove) 위 3번을 다시 하면 된다.

## 쓰는 법

1. Figma에서 찍을 화면들을 **드래그로 감싸 고른다**(섹션을 고르면 그 안 화면까지 들어간다).
2. Plugins → Development → **검수 화면 보내기** 실행.
3. 목록을 눈으로 확인하고 **보내기**.
4. 촬영 준비 사이트로 가면 ② 찍을 목록에 그대로 들어와 있다.

폭이 1400 이상인 화면은 목록에 ⚠︎ 로 표시된다 — 폰으로 찍을 화면치고 넓다는 뜻(웹 시안을 잘못 고른 경우).

## 검수 시안 바꾸기 (2026-09-10)

고른 프레임에 이미 검수 화면이 있으면(검수 포털 8765가 켜져 있을 때) 주황 단추 **검수 시안 바꾸기**가 뜬다.
촬영 준비를 거치지 않고 그 페이지의 시안만 새 판으로 갈아끼운다 — 그림 + 검수기와 같은 모양의 요소 목록 + 검수기에서 정한 설정.
Figma 토큰이 필요 없다. 옛 판과 핀은 그대로 남고, 자동 검수 후보는 새 시안으로 다시 찾는다.
