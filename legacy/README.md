# 레거시 — 지금은 쓰지 않는 것 (이력 보관용)

여기 있는 것은 **현재 작업에서 부르지도, 읽지도 않는다.** 지난 결정을 되짚기 위해 남겨 둘 뿐이다.
새 코드가 여기를 참조하면 안 된다. 여기 파일을 고칠 일도 없다.

## plugin-image-qa — 피그마 「개발화면 검수기」 플러그인 (2026-09-14 폐기)

river 결정(2026-09-14): **앞으로 검수는 포털에서만 한다.** 피그마 플러그인 창은 쓰지 않는다.

| 파일 | 무엇 |
|---|---|
| `manifest.json` · `code.js` | 피그마 플러그인으로 띄우는 데 필요했던 것 (프레임 고르기·이미지 내보내기·캔버스 번호 표시) |
| `README.md` | 그때의 사용 설명 |
| `test.js` | 플러그인 쪽 자체 검사 (`npm run test:image:legacy` 로만 돈다) |

**비교 엔진은 여기 없다.** 규칙·비교 알고리즘 한 벌은 `engine/ui.html` 로 옮겨 살아 있고, 포털이 그 파일을
`/engine/ui.html` 로 내보내 숨은 틀에서 돌린다. 즉 폐기한 것은 **창**이지 **엔진**이 아니다.

`engine/ui.html` 안에는 아직 그 시절 플러그인 화면(번호 패널·판정 단추 등)의 코드가 남아 있다.
포털은 그 부분을 쓰지 않는다. 걷어내는 것은 나중 정리 조각으로 미룬다(지금 건드리면 규칙까지 흔들린다).

관련: `mvp0/policy_api.py`(검수기↔포털 규칙 배선)도 부르는 쪽이 없어졌다. 파일은 제자리에 두되 사용하지 않는다.
