# 시험지 — 손대지 않는 자리

여기 있는 것은 **채점표**다. 검수기를 만드는 쪽(구현)은 이 폴더를 고치지 않는다.

| 자리 | 무엇 |
|---|---|
| `목록.json` | 공식 측정이 도는 화면 15개와 정답 목록 |
| `세트/` | 화면마다 시안 그림 · 개발 그림 · 시안 요소 |
| `정답/` | river가 직접 확인한 진짜 오류(체류시간 7건) |
| `도구/` | 재는 도구(run.js) · 정답 세는 도구(answers_check.js) |
| `양면/` | 규칙마다 '드러나야 할 것 / 접혀 있어야 할 것' 한 장씩 |
| `기준.md` | 무엇을 보고 '됐다'고 하는가 |

고쳐야 할 일이 생기면 **멈추고 river에게 올린다.** 시험지를 고치면 앞서 잰 성적과 견줄 수 없고,
문지기가 "측정한 뒤 시험지가 바뀌었다"며 문을 닫는다(그때는 다시 재야 한다).

`양면/` 만은 규칙마다 새 장이 늘어나는 자리라 재는 지문에서 뺀다 — 장이 하나 는다고
앞서 잰 성적이 못 쓰게 되지는 않는다. 대신 양면 시험지 한 장의 지문은 그 시험 결과에 따로 적힌다.
