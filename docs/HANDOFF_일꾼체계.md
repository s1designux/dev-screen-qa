## 6. 남은 사실 (숨기지 않고)
- 시험 화면 20장 중 **정답이 달린 것은 체류시간 한 장(7건)뿐**이다. 나머지 19장은 볼 것 수만 센다.
- 새로 넣은 다섯 화면은 볼 것이 2~5건으로 적다. 근거로 쓰기엔 아직 얇다.
- 새 웹 화면 셋(가입약관·웹로그인실패·웹로그인커서)이 **같은 로고 크기 차이**를 함께 짚는다
  (시안 169px · 개발 183px, 8% 큼). 그림으로 확인한 진짜다 — 서로 다른 화면에서 같은 원인이
  나온 것이라, 서비스 공통 규칙을 올릴 때 쓸 근거다.
- `시험화면후보/` 는 깃에 안 올린다(`.gitignore`). 넣고 나면 `시험지/세트` 가 정본이다.
- 공식 측정 중 크롬이 한 번 죽어 화면 하나를 못 잰 적이 있다(014). 그때는 **판정 불가**이고
  다시 재는 것이 맞다 — 빠진 채로 합계를 내지 않는다.
- 본 폴더 `~/dev-screen-qa` 에 아직 커밋되지 않은 검수기 수정(세로 정렬을 윤곽으로 다시 보는
  조각)이 있다. 지금 성적은 그것을 넣지 않은 판이다.
