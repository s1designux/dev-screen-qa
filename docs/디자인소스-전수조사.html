7색·크기 값은 어긋난 곳이 없습니다

점검기가 화면 파일 52장을 훑어 0곳입니다. 값은 전부 토큰으로 되어 있습니다.

그래서 이번에 나온 것은 전부 값이 아니라 부품 문제입니다. 점검기는 "이 색이 토큰인가"만 보고 "이 단추가 정본 단추인가"는 못 봅니다.

세는 법 — 정본 부품을 쓴다 = 마크업에 data-s1-component 표시가 있고 정본 CSS 를 입는다. 손으로 만든 것 = 정본에 같은 부품이 있는데 화면 쪽에서 직접 짠 것.
