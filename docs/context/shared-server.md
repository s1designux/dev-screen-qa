# 공용 PC 한 대를 서버로 (2026-11-02)

river 질문: 디자인그룹 공용 PC 에 포털을 두고, 각자 자리 PC 에서도 쓰고 저장하게 하려면?

## 결정
- **자료는 공용 PC 한 곳에만 쌓인다.** 자리 PC 는 브라우저로 `http://공용PC주소:8765` 에 들어온다. 따로 깔 것 없음.
- 누가 했는지는 로그인한 이름으로 남는다(포털 문 잠그기 — `portal-login-accounts.md`).
- 공용 PC 는 동료 공유를 켜고 띄운다 — 윈도우 `포털-켜기-윈도우.bat`, 맥 `포털-동료공유-켜기.command` 가 이미 켠다.

## 이번에 고친 것
1. **여럿을 동시에 받는다** — 포털 서버가 한 사람씩 처리하던 것을 동시에(`ThreadingHTTPServer`).
2. **동시에 저장해도 안 깨진다** — 자료함을 WAL 로, 쓰는 사람이 겹치면 15초까지 기다린다(`db.connect`).
   그래서 자료함 옆에 `-wal`·`-shm` 파일이 생긴다(깃 제외). 백업은 파일 복사가 아니라 sqlite 백업으로 뜬다(윈도우 ps1 도 바꿈, 맥은 원래 그랬다).
3. **사무실 밖은 막는다** — 부른 이름과 실제로 보낸 PC 주소를 둘 다 본다(포털·촬영 준비 둘 다). 바깥 PC 가 localhost 라고 적어 보내도 막힌다(독립 검토가 찾은 구멍).
4. **촬영 메뉴가 자리 PC 에서도 열린다** — 포털 안에 끼우는 촬영 준비 주소를 127.0.0.1 이 아니라 브라우저가 부른 이름으로 짓는다. 촬영 준비 → 포털로 돌아가는 주소도 같다.
5. **피그마 플러그인 '포털 주소' 칸** — 비우면 내 PC(localhost), 공용 PC 주소를 적으면 그리로 보낸다. Figma 가 PC 마다 기억한다.
   manifest 는 `allowedDomains: ["*"]` (사무실마다 주소가 달라 미리 못 적는다).

## 주의
- **촬영은 한 번에 한 사람.** 촬영 준비 사이트는 진행 중인 작업이 한 벌(`작업.json`)뿐이다. 여럿이 동시에 촬영을 준비하면 서로 덮어쓴다.
  앱 촬영은 폰을 꽂은 PC(공용 PC)에서만 된다.
- **확인 못 한 것:** 자리 PC 의 Figma 데스크톱이 http 사설 주소로 실제로 보내지는지(Figma 문서에 사설 IP 언급 없음). 첫 자리 PC 에서 한 번 보내 봐야 한다.
  안 되면 그 자리 사람은 시안 보내기만 공용 PC 의 Figma 에서 한다.
- **주소는 숫자(IP)로 부른다.** 포털·촬영 준비 모두 사무실 IP·localhost 로 부른 것만 받는다(이름 바꿔치기 막기). 컴퓨터 이름(`design-pc.local` 등)으로는 403.
- 공용 PC 주소는 고정 IP 로 받아 두는 것이 좋다(바뀌면 플러그인 칸·즐겨찾기를 다시 적어야 한다).
