동작 문법을 사람이 외우게 하지 않는다. 두 갈래로 받친다 — ① 그림에서 고르기에서 **적는 칸**(초록 점선)을 누르면
"무슨 글자를 넣을까요?" 만 묻고 `입력 <칸>=값` 문장은 도구가 짓는다. ② 틀리게 적으면 빨간 글로 혼내는 대신
**"이렇게 쓰신 거죠? [이대로 바꾸기]"** 로 고친 문장을 내민다(자동으로 바꾸지 않는다).

**Why:** river님 스스로 `<1234> 입력` 이라고 적고 막혔다. 동료 배포 때 같은 일이 더 크게 난다.

**How to apply:** 새 규칙 말을 더할 때마다 `lib/actions.py` 의 같은말 표와 고쳐보기도 함께 늘린다.
말로 적게 두는 세 번째 갈래(사내 클로드)는 아직 안 함. 관련: [[capture-action-autofill]] · [[capture-site-rules]]
