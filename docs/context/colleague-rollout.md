동료에게 촬영기를 어떻게 나눠줄지 2026-09-14 river와 정리한 결론.

- **촬영기(Playwright)로 간다.** 엣지 확장 방식은 화면마다 사람이 눌러야 해서 탈락 — 검수 대상이 수백 장이다.
- **각자 PC에서 돈다.** 한 대에 몰아 두는 방식은 river가 거부.
- **받는 길은 깃허브 링크 하나.** 공유폴더는 접는다(내부망 PC에 관리자 권한이 없어 폴더 공유가 막힐 수 있음). 내부망 PC도 깃허브 내려받기는 열려 있다.
- **설치는 사내 클로드가 대신 한다.** 묶음 안에 클로드가 읽을 설치 지시서를 한 장 넣고, 동료는 링크 주고 "설치해줘" 한마디. 동료들의 사내 클로드는 토큰이 있으면 파일·명령을 직접 다룰 수 있다(river 확인).
- **pip 이 보안에 막히는 경우가 있다** → 지시서가 두 갈래를 알아야 한다. 평소 방식으로 해 보고 막히면 깃허브에 따로 올려둔 설치 파일로 대신 깐다.
- **실제 주소·계정은 공개 저장소에 못 올린다**(§11 설정.json) → river가 따로 건네고 클로드가 받아 적는다.
- **서버는 내부망 PC 한 대.** 기록은 전부 포털로 쌓이고, 공유폴더에 자료를 직접 쌓지 않는다.
- **착수 시점: 값 대조 조각([[value-qa-token-rules]])을 끝낸 뒤.** (river 결정 2026-09-14)

브라우저만으로는 불가능한 이유: 웹페이지는 다른 사이트 화면을 재거나 찍을 수 없다. 그래서 순수 포털 웹 기능으로는 대체 못 한다.
