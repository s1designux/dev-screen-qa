2026-09-07 river 확정. **재논의하지 않는다.**

**결론:** 로컬 비전 AI(Qwen2.5-VL)는 **디자인그룹 사용자에게 배포하는 기능이 아니다.**
검수기 제작 담당자가 **새 검수 규칙을 발굴·검증**할 때만 쓰는 도구다.
사용자는 검수기만 쓰고, **배포하는 것은 AI가 아니라 규칙**이다.

**역할 분담:** 검수기=위치·크기·색 재기 / 로컬AI=필요할 때 글자 읽기·새 패턴 찾기 /
담당자=반복 패턴을 룰로 전환 / 사용자=정리된 결과만 확인.

**근거(실측):** 화면당 약 9분(검수기 1초) · 아이콘 판독 실패 · 없는 글자 생성 ·
가변 자리 판단 불가 · 같은 설정을 함께 배포해야만 재현 · 판정 근거 설명 불가.
효과가 확인된 자리는 **글자 판독과 헛지적 감소**뿐: 정답 검출 21/25→25/25, 사람이 볼 항목 93→12.
