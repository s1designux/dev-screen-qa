**확정된 판단 (river):**
- 피그마 프로토타입 연결선 읽기는 안 한다 — 시안 작업이 늘어나므로. 시안에 손대지 않는 방식만.
- 자동 채움도 '초안'이다. 짚은 근거를 화면에 보이고 사람이 고친다(2번-2).
- 요소는 플러그인이 포털용으로 이미 보내는 12단계 전체 목록(`디자인/NNN_elements.json`)에서 읽는다. 6단계 얕은 `속`은 검색줄 속 셀렉박스를 놓쳤다. 다시 읽지 않으니 느려지지 않는다.

**실측 (삼성통근버스 시안 3페이지, 상태 화면 402장):** 눌러서 만드는 상태 약 36% / 자료·계정 조건 약 40~50% / 스크롤·호버 7%.
자료 조건 화면은 어떤 방식으로도 못 만들므로 목록에서 표시만 한다.
