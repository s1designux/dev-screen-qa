# 직접 넣는 검수 (자동 촬영이 안 되는 과제) — 2026-10-30

river 확정 C안: 시안은 플러그인으로 보내거나(부품 정보 → 지금 검수기 그대로) 그림으로 붙여 넣는다(그림끼리 견주기). 개발 화면은 캡처를 붙여 넣는다.

- 입구: 묶음 안 페이지 카드 맨 앞 '페이지 직접 만들기'(`project_view._페이지추가` → `screen_add.페이지만들기`). 1차 run 을 빈 채로 세운다.
- 넣기: 페이지 상세 양쪽 '붙여넣기'(⌘V) · 'PNG 업로드'. 시안 그림 → `design_receive.paste`(provider '직접 넣은 그림', file_key 'pasted', 빈 요소 목록). 개발 그림은 바꿀 때마다 새 이름 + `page_capture_event`.
- 플러그인 시안이 걸린 페이지는 그림으로 덮지 않는다(서버에서 막음).
- 견주기: `auto_inspect.PICTURE_JS`(엔진 파일 밖, 포털 손잡이). 같은 폭으로 맞추고 세로 자리 한 번만 찾음 → 둘레 한 칸 양쪽 대조 → 다른 구역을 후보로. 띠마다 따로 옮기면 차이를 피해 가 감춘다(검증에서 확인, 걷음).
- 검증(독립): 빨간 막대 합성·실제 웹/앱 쌍 통과. 남은 것: 위쪽 범위를 자르면 겹쳐보기 시작 자리가 16px 어긋날 수 있음 · 어둡게 덮인(모달) 화면은 자리를 잘못 잡지만 통째로 후보가 됨 · 앱 상태바는 후보로 올라옴(검수 범위로 자름).

## 줄 길이·면 색 (2026-10-30 river 지시)
- 한 줄 조각은 시안에서 글자가 이어진 사이(줄 높이보다 긴 빈칸 없음)일 때만 묶고, 줄 길이가 다르면 '글자 줄 길이가 다른 곳'(줄 길이 A → B px) 하나로. 3~10칸 높이·길이 비 0.5~2배일 때만 잰다.
- 한 색으로 칠한 면은 문턱 6으로 본다('색상이 다르게 보이는 곳', 시안 #hex → 개발 #hex). 둘레에 서로의 색이 있으면 옮겨진 면이라 뺀다.
- 이 규칙 지문은 그림으로 넣은 페이지에만 붙는다(engine_rev(design)) — 고치면 그 페이지들만 다시 돈다.
- 독립 검토 14가지 경우 통과. 웹 로그인 쌍 후보 11 그대로.

## 글자 줄을 원래 크기로 (2026-10-30 river 지시 — '이상' 말고도 두루)
- 시안 글자 줄마다 원래 크기로 다시 본다(`__portalTextLines`): 앞에서·뒤에서 각각 맞춰 처음 어긋나는 자리를 찾아 바뀐 구간을 짚는다 → 왼·가운데·오른 맞춤 모두.
- 이름표: 글자가 빠진 곳 / 더해진 곳 / 다른 곳 / 크기가 다른 곳(글자 높이) / 자리가 다른 곳 / 보이지 않는 곳 / 배치가 달라진 문단 / 화면 전체가 다른 곳(맞출 수 없음 — 덮인 창 등, 점수 30 넘음).
- 빠짐·더해짐은 그 자리 말고 앞뒤가 짧은 쪽 줄의 6할 이상 맞을 때만. 그리는 방식만 다른 줄(넓게 조금씩)은 '다른 곳'으로 낮춰 말한다.
- 독립 검토: 합성 A–F(가운데·오른쪽·문단·같은 너비 바꿈·줄 끝·마침표)·사용자 대화창·실제 웹 쌍 4개. 남은 것 하나: 가려진 비밀번호 줄(* 15개 → • 8개)을 '빠진 곳'으로 말함.
