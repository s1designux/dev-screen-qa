# 직접 넣는 검수 (자동 촬영이 안 되는 과제) — 2026-10-30

river 확정 C안: 시안은 플러그인으로 보내거나(부품 정보 → 지금 검수기 그대로) 그림으로 붙여 넣는다(그림끼리 견주기). 개발 화면은 캡처를 붙여 넣는다.

- 입구: 묶음 안 페이지 카드 맨 앞 '페이지 직접 만들기'(`project_view._페이지추가` → `screen_add.페이지만들기`). 1차 run 을 빈 채로 세운다.
- 넣기: 페이지 상세 양쪽 '붙여넣기'(⌘V) · 'PNG 업로드'. 시안 그림 → `design_receive.paste`(provider '직접 넣은 그림', file_key 'pasted', 빈 요소 목록). 개발 그림은 바꿀 때마다 새 이름 + `page_capture_event`.
- 플러그인 시안이 걸린 페이지는 그림으로 덮지 않는다(서버에서 막음).
- 견주기: `auto_inspect.PICTURE_JS`(엔진 파일 밖, 포털 손잡이). 같은 폭으로 맞추고 세로 자리 한 번만 찾음 → 둘레 한 칸 양쪽 대조 → 다른 구역을 후보로. 띠마다 따로 옮기면 차이를 피해 가 감춘다(검증에서 확인, 걷음).
- 검증(독립): 빨간 막대 합성·실제 웹/앱 쌍 통과. 남은 것: 위쪽 범위를 자르면 겹쳐보기 시작 자리가 16px 어긋날 수 있음 · 어둡게 덮인(모달) 화면은 자리를 잘못 잡지만 통째로 후보가 됨 · 앱 상태바는 후보로 올라옴(검수 범위로 자름).
