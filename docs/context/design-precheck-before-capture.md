river님 방향: **디자인 오류는 촬영 전에 잡는다.** 페이지 상세에 '디자인 몫' 탭을 붙이는 안은
논의 끝에 접고, 대신 촬영 준비 사이트의 **접수 직전**에 '시안 점검 한 장'을 둔다.

시안만으로 보는 것 셋: ① 토큰·컴포넌트 규정 대조(조각 ②의 자를 시안 쪽에만 돌림, 새 자 금지)
② 촬영 대본에 나오는 상태의 시안 프레임이 있는지 ③ 프레임 이름·화면 사람키 규칙.
못 보는 것(글자 넘침·실제 창 높이 깨짐)은 페이지 상세에 남긴다.

**Why:** 2026-09-14 우비스 웹 로그인에서 못 찍은 4장 중 '비밀번호 숨김 해제 상태'가
시안 자체에 없던 건이었다. 개발 탓도 대본 탓도 아닌 시안 결손인데, 촬영 뒤에야 드러났다.

**How to apply:** 점검 미통과로 촬영을 자동 차단하지 않는다(사람이 보고 넘김).
