2026-09-03 `plugin-image-qa/`에 글자 가변·불가변 판별 조각을 넣었다(사용자 승인 계획대로).
- 규칙 순서: 사람 판정 > 글자 꼴(숫자·날짜·자리표시=가변, "…해 주세요"·회사정보=고정) > 컴포넌트 역할 이름 > 반복 행(3개↑·두 줄↑·각 2요소↑) > 버튼 모양 > 화면 종류(공통=고정 / 일반=가변).
- 공통화면 목록(사용자 확정): 로그인·회원가입·아이디/비밀번호 찾기·약관·오류·빈 상태. 화면 이름으로 추정, 패널 스위치로 변경, 디자인 프레임 pluginData(`imageQaPolicy`)에 저장.
- 가변 글자는 숨기지 않고 '가변 글자·요소' 접힌 묶음(status `variable`)으로. 색·높이 차이·누락은 검토 유지.
- 표 재현 세트: `validation-image-qa/repro/table_mock.html` + `make_table_case.js` → `design_table_1200x700.png`/`dev_table_1200x700.png`/`elements_table(.noname).json`.

**확인된 별건 엔진 한계(다음 조각 후보):** 같은 글꼴·13~14px 짧은 글자를 같은 길이로 바꾸거나(조회→검색) 뒤에 글자가 더 붙는 경우(연락처→담당자 휴대전화번호)를 "같다"고 본다. 디자인 글자 상자 안의 윤곽만 비교하고 1px 허용이 작은 글자에서 포화하기 때문. 글꼴이 다르면 잘 잡힘.

**Why:** 사용자는 "전체 9,999 vs 전체 9" 같은 데이터 차이가 오류로 잡히는 것을 문제 삼았고, 이미지만으로는 불가능하므로 디자인 쪽 구조 정보로 헷징하기로 했다.
**How to apply:** 가변 판정을 자동 '오류아님' 확정으로 승격하지 말 것. 엔진 민감도 개선은 별도 조각으로 범위 확인 후 착수. 관련: [[image-qa-repro-findid]], [[image-qa-range-chrome]].
