페이지 상세의 후보 카드 본문은 `mvp0/card_view.py` 한 곳에서 그린다(2026-09-14).
규칙: ① 같은 값을 두 번 적지 않는다(옛 '디자인 원본값' 줄은 없앴다) ② 표는
[무엇이 · 지금 개발 · → · 디자인 기준] 네 칸, 잰 값이 없는 그림 검수 후보는 두 칸 ③ 아래에
'개발이 볼 자리'(선택자) · '디자인 컴포넌트' · '화면 자리'를 따로 묶는다 ④ 기준값에 토큰 이름이
있으면 헥사 밑에 그 이름을 적는다.

**Why:** 회색 글줄이 줄줄이 붙어 있어 무엇이 기준이고 개발이 어디를 봐야 하는지 안 보였다
(river 2026-09-14). 화살표는 '지금 → 기준' 방향이다 — 개발이 고칠 방향으로 읽히게.

**How to apply:** 값 대조 후보는 `auto_candidate.policy` 의 `줄`·`자리`(값째로 저장, 글월 되읽기 없음)를
쓴다. 카드 모양을 바꿀 때는 `value_candidates.지문()` 의 앞머리(`value2:`)를 올려 새 회차로 다시 재게 한다
— 옛 회차는 남고 사람 판정은 이어받는다. 토큰 이름은 시안 플러그인(`capture-app/plugin-pick/code.js`
`요소토큰`)이 변수·스타일에서 읽어 요소마다 `토큰` 칸으로 싣는다. 레거시 화면은 비어 있어 헥사만 보인다.
