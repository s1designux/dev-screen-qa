# 화면에 적는 글 규칙 (포털 · 촬영 준비 사이트 공통)

화면에 적히는 모든 글(제목·안내·단추·오류·빈 화면 문구)은 이 규칙을 따른다.
**명확하고 짧게, 그러나 딱딱하지 않게.** 문서가 아니라 옆에서 알려주는 말투다.

---

## 1. 일곱 줄 규칙

1. **한 가지는 한 번만.** 제목이 이미 말한 것을 본문에서 되풀이하지 않는다.
   숫자·건수도 한 자리에서만 말한다.
2. **안내는 두 줄까지.** 세 줄이 되면 무언가를 빼야 한다는 뜻이다.
   더 필요하면 접는 칸(▾)이나 별도 도움말로 내린다.
3. **"무엇을 하면 되는지"로 끝낸다.** 배경·이유·원리는 적지 않는다.
   꼭 필요한 이유는 **한 조각**만 붙인다.
4. **말투는 하나로.** 서술은 `~합니다`, 부탁은 `~하세요`, 막혔을 때는 `~할 수 없습니다` + 할 일 한 줄.
   `~해요/~예요` 와 `~합니다` 를 한 화면에서 섞지 않는다.
5. **문서체·관공서체 금지.** 아래 말은 쓰지 않는다.
   - 제공하지 않습니다 / 진행합니다 / 보존됩니다 / 등록 절차 / 해당 항목 / ~에 대하여
   - 대신: 아직 못 합니다 / 합니다 / 그대로 남습니다 / 이름 / 이것
6. **화면에 보이는 말로.** 코드 이름·영어 이름·내부 용어를 그대로 쓰지 않는다.
   단, 이 시스템의 이름(차수·후보·지적·접수함·검수 페이지)은 그대로 쓴다 — 여기저기서 다르게 부르지 않는다.
7. **사과하지 않는다.** "죄송합니다", "오류가 발생하였습니다" 대신 무엇이 어긋났고 지금 무엇을 하면 되는지만.

## 2. 자리별 길이

| 자리 | 길이 | 보기 |
| --- | --- | --- |
| 단추 | 2~6자, 동사로 | `삭제` `페이지 옮기기` `다시 검수` |
| 제목 | 한 줄, 숫자는 옆에 | `검수 페이지 · 10개` |
| 안내(카드 본문) | 최대 두 줄 | `색·크기·글꼴이 시안과 다른 곳, 27곳입니다.` |
| 도움말(작은 회색) | 한 줄 | `비워 두면 '—' 로 남습니다.` |
| 오류 | 한 줄 + 할 일 한 줄 | `같은 이름의 파일이 두 개 있습니다. 폴더 하나씩 가져와 주세요.` |
| 빈 화면 | 한 줄 + 첫 할 일 | `아직 검수한 것이 없습니다. 시안을 연결해 시작하세요.` |

## 3. 고쳐 쓴 보기

| 전 | 후 |
| --- | --- |
| 값으로 확인된 차이가 27곳 있습니다. 색·크기·글꼴처럼 값으로 딱 떨어지는 것과, 회사 토큰·공통 컴포넌트 규정에 어긋난 것입니다. 사람이 눈으로 보는 검수를 시작하기 전에 개발이 먼저 반영해야 같은 지적을 차수마다 되풀이하지 않습니다. | 색·크기·글꼴이 시안과 다르거나 회사 색·컴포넌트를 쓰지 않은 곳, **27곳**입니다.<br>**검수를 시작하기 전에** 개발이 먼저 고치면 같은 지적을 되풀이하지 않습니다. |
| 개발·퍼블리셔에게 그대로 넘기는 문서입니다. 자동으로 찾은 후보이며 확정은 디자이너가 합니다. PDF 보기는 내려받지 않고 그 자리에서 읽고, 눌러서 PDF 로 저장합니다. | (지운다 — 단추 이름이 이미 말하고 있다) |
| 지적이 등록된 화면의 개발 화면 교체는 새 차수에서 진행합니다. | 지적이 있는 화면은 새 차수에서 바꿉니다. |
| 검수를 시작한 항목의 이름·대상 변경은 이번 단계에서 제공하지 않습니다. | 검수를 시작한 뒤에는 이름을 바꿀 수 없습니다. |
| 두 이미지가 같은 상태인지 확인하세요. 확인 후에도 이 화면에서 이어집니다. | 두 그림이 같은 상태인지 확인하세요. |

## 4. 이름표 (한 가지 것은 한 이름으로)

화면에서 쓰는 이름은 이 표가 전부다. 코드 안에서 뭐라 부르든, **화면에는 왼쪽 말만** 적는다.

| 화면에 적는 말 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 수정필요 | 사람이 확정해 고쳐야 할 것 | 지적, 이슈, 오류 등록 |
| 후보 | 검수기가 찾아 둔 것(아직 확정 아님) | 자동 오류, 검출 |
| 제외 / 가변 | 사람이 후보를 내린 자리 | 무시, 스킵 |
| 처리됨 | 협의통과·검수완료·오류아님 | 완료, 종료 |
| 차수 | 1차·2차 재검수 | 회차, 라운드 |
| 검수 페이지 | 화면 한 장(상태 하나) | 시나리오, 케이스 |
| 시안 | 디자인 원본 | 디자인, 목업, 피그마 |
| 접수함 | 촬영본이 들어오는 자리 | 인테이크, 배치 |

## 5. 지켜지는지 세는 법

`python3 scripts/글점검.py` — 화면 글만 골라 **옛 이름 · 문서체 · 말투 섞임 · 너무 긴 안내** 네 가지를 짚는다.
어긋난 곳이 있으면 종료코드 1. **문장은 사람이 정한다** — 이 도구는 짚기만 하고 고치지 않는다.

새 화면·새 문구를 만들면 커밋하기 전에 한 번 돌린다. 새로 금지할 말이 생기면
`scripts/글점검.py` 의 `문서체` · `옛이름` 표에 한 줄 더한다(코드가 원본, 이 문서는 사람이 읽는 사본).

## 6. 쓰기 전 점검 네 가지

- 제목을 지워도 뜻이 통하나? → 통하면 본문이 제목을 되풀이하는 것이다.
- 첫 문장만 남기면 안 되나? → 되면 나머지는 뺀다.
- 이 문장이 사용자의 **다음 행동**을 바꾸나? → 안 바꾸면 뺀다.
- 소리 내 읽어 어색한가? → 문서체가 섞인 것이다.
